# Личная страница — Егор Макухин

Одностраничный сайт-визитка на **Bootstrap 5.3** в тёмной теме с янтарным акцентом.
Без сборки и зависимостей: достаточно открыть `index.html` в браузере.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка: навигация, hero, Soft skills, Hard skills, контакты |
| `style.css` | Цвета, типографика, карточки, анимации |

## Как открыть

Просто откройте `index.html` двойным кликом. Если нужен локальный сервер:

```bash
cd about-me
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Если сервер уже запущен из домашней папки, страница доступна по адресу
`http://localhost:8000/about-me/`.

## Что заменить

1. **Имя и подпись** — заголовок `h1` в hero-блоке, `.hero-role`, `<title>` и `meta description`.
2. **Фото** — уже установлено: файл `avatar.jpg` (квадратный кроп 900×900,
   лицо по центру) выводится в круглой рамке. Чтобы заменить фото, положите своё
   изображение с именем `avatar.jpg` в папку страницы — разметку менять не нужно.
3. **Контакты** — карточки почты, Telegram `@ioughy` и GitHub `ioughy` оформлены
   одинаково. Клик по почте открывает окно нового письма в Gmail с заполненным адресатом.
4. **Soft skills** — шесть карточек в секции `#soft-skills`: текст, заголовок и иконка
   Bootstrap Icons (`<i class="bi bi-…"></i>`).
5. **Hard skills** — секция `#hard-skills`: языки и вёрстка (C, Python, Kotlin, Go,
   HTML/CSS), окружение (Linux, Bash, Git, Docker, CMake, CI/CD), базы
   (PostgreSQL, Redis) и документация (LaTeX, Markdown).
6. **Год в подвале** подставляется скриптом автоматически.

## Цвета

Палитра собрана в CSS-переменных в начале `style.css`:

```css
--bg: #131316;       /* фон */
--surface: #1c1c20;  /* карточки */
--text: #e8e8ec;     /* основной текст */
--muted: #a1a1aa;    /* второстепенный текст */
--accent: #f59e0b;   /* янтарный акцент */
```

Поменяв `--accent`, вы перекрасите кнопки, иконки, ссылки и выделения сразу по всей странице.

## Особенности

- Адаптивная сетка Bootstrap (mobile-first), меню-бургер на телефонах.
- Плавное появление блоков при прокрутке (IntersectionObserver).
- Поддержка `prefers-reduced-motion` и видимый фокус для клавиатуры.
- Bootstrap и иконки подключены с CDN с проверкой SRI.
